# Android Studio on Linux

[Intstalling Android Studio on 64-bit version of Lubuntu fails installing some 32-bit libraries](https://stackoverflow.com/questions/58681718/intstalling-android-studio-on-64-bit-version-of-lubuntu-fails-installing-some-32)   

`Note: Linux machines with ARM-based CPUs aren't currently supported.`

```
uname -m
sudo mv /home/d76x/Downloads/AndroidStudio/android-studio-quail1-patch2-linux/android-studio /usr/local/
sudo add-apt-repository universe
sudo apt-get update
sudo apt-get install libc6:i386 libncurses5:i386 libstdc++6:i386 lib32z1 libbz2-1.0:i386
sudo apt-get install  libncurses6:i386

cd /usr/local/android-studio/bin
./ studio &
```

0. check that your architecture is a `x86_64` and NOT `arm..` as the latter is not supported by Android Studio
1. Download the `.tar.gz` from [Android Studio Downloads](https://developer.android.com/studio)
2. Unpack the `.tar.gz`
3. Move the `android-studio` to the `/usr/local/`
4. Add the universe repo to apt `sudo add-apt-repository universe`
5. update apt: `sudo apt-get update`
6. install the Android Studio prerequisite libs: `sudo apt-get install libc6:i386 libncurses5:i386 libstdc++6:i386 lib32z1 libbz2-1.0:i386`
7. is you get an error such as `E: Unable to locate package libncurses5:i386` try to replace them with something more recent as the command that you copy and paste from `https://developer.android.com/studio` may be outdated, for example `sudo apt-get install  libncurses6:i386` with `libncurses6:i386` instead of `libncurses5:i386`
8. Run `/usr/local/android-studio/bin/studio` to set Android Studio up or to run the IDE

## How do I know whether my Ubuntu is ARM based?

`uname -m`

In the Terminal: 

- if it returns `x86_64` your system is x86
- If it returns `arm64` , `armv7l` , or similar, it is ARM.
